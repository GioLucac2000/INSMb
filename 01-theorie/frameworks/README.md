# Frameworks

Eén bestand per model. Elk bestand heeft hetzelfde stramien:

1. **Wat is het** (1 zin) 2. **Analogie** 3. **De onderdelen** 4. **Voorbeeld**
5. **Checkvragen** (zelf beantwoorden!) 6. **Valkuilen op het tentamen**

## Volgorde die logisch is voor een case

| Stap | Vraag | Model |
| --- | --- | --- |
| 1 | Wat gebeurt er in de wereld? | PESTEL |
| 2 | Hoe aantrekkelijk is deze markt? | Porter 5 Forces |
| 3 | Waarom is dit land aantrekkelijk? | Porter Diamant, CAGE |
| 4 | Wat kunnen wij? | Value Chain, VRIO |
| 5 | Waar botst dat? | SWOT-confrontatiematrix |
| 6 | Hoe winnen we? | Generieke strategieën, Blue Ocean |
| 7 | Waar groeien we? | Ansoff, BCG |
| 8 | Hoe gaan we het land in? | Entry modes |
| 9 | Hoe organiseren we het? | Bartlett & Ghoshal |
| 10 | Hoe gaan we met cultuur om? | Hofstede |
